# Java Learning Lab

An interactive, local-first Java curriculum from JDK and language foundations through concurrency, PostgreSQL, server frameworks, JVM engineering and production delivery. Visual Studio Code is the primary learning environment; platform differences are called out for Windows, macOS and Linux.

- Open `index.html` for local review, or serve this directory with any local static HTTP server.
- Module links open focused lessons in new tabs.
- Completion, quiz results and drafts remain in browser local storage and can be reset.
