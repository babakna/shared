# C# Learning Lab

An interactive, local-first C# curriculum from .NET and language foundations through async systems, PostgreSQL, ASP.NET Core, cross-platform clients, CLR engineering and production delivery. Visual Studio Code is the primary learning environment; platform differences are called out for Windows, macOS and Linux.

- Open `index.html` for local review, or serve this directory with any local static HTTP server.
- Module links open focused lessons in new tabs.
- Completion, quiz results and drafts remain in browser local storage and can be reset.
