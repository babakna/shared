# Python Learning Lab

An interactive, local-first Python curriculum from foundations through automation, data, backend engineering, machine learning and AI. Visual Studio Code is the primary learning environment; platform differences are called out for Windows, macOS and Linux.

- Open `index.html` for local review, or serve this directory with `python3 -m http.server`.
- Module links open focused lessons in new tabs.
- Completion, quiz results and drafts remain in browser local storage and can be reset.
